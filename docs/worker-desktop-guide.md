# Worker desktop — published r10

Download the Worker from the lab's download page. Enter its address, sign in, install the pinned runtime, run the
compatibility check, choose the device name and pair it. A platform administrator approves the device into a workspace
that its owner belongs to. Contribution starts OFF after each boot and remains an explicit owner choice.

Use the station to enable/stop contribution, inspect resource observations and export diagnostics. Process ownership
must be confirmed stopped before changing role/endpoints or forgetting a pairing. "Forget this pairing" works offline
while OFF; it clears local pairing, while the old lab retains device history. Revoked devices require a new enrollment.

Same private LAN/overlay routes support replay and full synchronization. A public route without private bulk access is
replay-only and stops when full weights are required. Coordinator mode is for a qualified Linux GPU with at least 11000 MB
VRAM. Windows is Recipe v1 worker-only. The first real Windows r10 trial is historical evidence; this cleanup adds no
new native Windows or GPU acceptance. See [quickstart-vi.md](quickstart-vi.md) and [HANDOFF.md](HANDOFF.md).
