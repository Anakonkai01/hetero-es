# Historical documents and prototypes

This folder preserves superseded M1/M2/M3 plans, handoffs, local setup notes, runtime agent guidance and the original
prototype zip. The current entry point is [../HANDOFF.md](../HANDOFF.md); the accepted cleanup plan is retained as
[refactor-plan-vi.md](refactor-plan-vi.md). Owner notes remain under `notes/`.

Historical paths and commands describe their original commits. Some point to retired scripts or former sibling
repositories. Use `git show <commit>:<path>` to reproduce a dated checkout; do not run those commands on the live lab.
Existing evidence and raw scientific artifacts are preserved in their original locations and were not rewritten.

`handoffs/` (moved 2026-10-23) holds every dated session handoff from 2026-10-19 to 2026-10-23 and the old stacked
`HANDOFF-history-2026-10.md`; superseded plans and qualification notes moved here at the same time. Links inside them
were rewritten to the new locations; dated evidence READMEs that name them in plain text keep the old path.
